Status: deferred for the initial version by the user. The initial-version draft interprets the latest instruction as automatic provider lookups within hunt scope; the historical decision below records the earlier plan. No approval lifetime was accepted.

External intelligence queries disclose indicators or search interests, so the harness requires analyst approval of a batch that identifies the provider, exact indicators or search filters, purpose, and query limit. Approved batches may execute automatically, but additional queries need another approval, trading some pivot speed for explicit control over external queries. Internal IOC lookups are allowed within the hunt scope, and the user separately permits full unclassified internal-source results in hosted model context; neither permission grants unrestricted external intelligence queries.
