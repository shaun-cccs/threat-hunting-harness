# Share hunt execution through an MCP gateway

Codex and Claude coordinators, investigation subagents, and evidence reviewers use one shared hunting MCP gateway with authoritative query history, evidence, status, and any user-configured limits. Provider integrations sit behind this interface, accepting a common execution dependency in return for consistent operation across clients and agents. The user later deferred the approval mechanism and selected no numeric limits by default; the shared gateway remains accepted independently of those controls.
